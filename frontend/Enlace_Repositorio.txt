## Descripción del proyecto

Para esta evidencia trabajamos en el desarrollo del frontend de nuestro proyecto formativo Noble Society, que consiste en una aplicación web para llevar el control y la administración de una barbería.

Durante el desarrollo utilizamos HTML, CSS y JavaScript, poniendo en práctica los conocimientos que hemos adquirido durante nuestra formación en el SENA.

Nuestro proyecto cuenta con diferentes módulos, como inicio de sesión, panel principal, clientes, citas, servicios, inventario y reportes.

También realizamos la conexión con el backend para poder registrar, consultar, editar y eliminar información almacenada en una base de datos MySQL.

Para desarrollar las diferentes páginas tuvimos en cuenta las funcionalidades que habíamos planteado anteriormente en nuestro proyecto. Además, organizamos el código, agregamos comentarios y realizamos pruebas para comprobar que los módulos funcionaran correctamente.

## Cómo ejecutar el proyecto

Para ejecutar nuestro proyecto es necesario descargar los archivos y abrirlos en Visual Studio Code.

Primero debemos ingresar a la carpeta `backend` y ejecutar el siguiente comando:

`npm run dev`

Después abrimos otra terminal, ingresamos a la carpeta `frontend` y ejecutamos:

`py -m http.server 5500`

Una vez iniciados los servidores, abrimos el navegador e ingresamos a:

http://localhost:5500/index.html

Para que todas las funciones trabajen correctamente, también es necesario tener configurada la base de datos MySQL.
